## 🎬 Guion sugerido para la sustentación

```
1. Registras una cuenta nueva (médico) con tu correo → llega BIENVENIDA 📬
   — o entras con el botón "Doctor" (Carlos)
2. Creas un caso (cualquier área) → se clasifica solo (ML)
3. Vas a "Abogados" → seleccionas el caso → contactas al abogado recomendado
   → llega "Nueva solicitud" 📨 a tu bandeja (+ese_abogado)
4. Entras como ese abogado (su correo de la tabla / Demo123!) → aceptas
   → llega "Solicitud aceptada" ✅ a tu bandeja (+carlos o tu cuenta nueva)
5. Muestras: bandeja Gmail + n8n → Executions (el Switch enrutando)
6. Entras como Admin → muestras usuarios, métricas del modelo, auditoría
```
